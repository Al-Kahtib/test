# test

A minimal [Express](https://expressjs.com/) server that returns JSON.

## Requirements

- Node.js 18 or newer

## Getting started

```bash
npm install
npm start
```

The server listens on port `3000` by default. Use the `PORT` environment variable to change it:

```bash
PORT=8080 npm start
```

During development, `npm run dev` restarts the server when files change.

## Endpoints

| Method | Path      | Response                                   |
| ------ | --------- | ------------------------------------------ |
| GET    | `/`       | `{ "message", "number", "isAwesome" }`     |
| GET    | `/health` | `{ "status": "ok", "uptime": <seconds> }`  |

Unknown routes return `404` with `{ "error": "Not found" }`.
